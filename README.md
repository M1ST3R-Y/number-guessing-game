
# Number Guessing Game

## Description

A simple console-based Python game where the player tries
to guess a randomly generated number between 1 and 100.

## Features

- Random number generation (1-100).
- Limited number of attempts (7 attempts).
- Interactive hints:
  - Too small!
  - Too large!
  - Congratulations!
- Input validation.
- Error handling for non-numeric input.
- Remaining attempts counter.
- Option to replay or exit the game.

## Requirements

- Python 3.x
- Standard Python library: random

No additional packages are required.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```

## How to Play

1. Run the program.
2. The computer generates a random number from 1 to 100.
3. Enter your guess.
4. Follow the hints provided by the program.
5. You have 7 attempts to guess the correct number.
6. After the game ends, choose whether to play again.
